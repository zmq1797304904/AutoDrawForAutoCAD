# AutoDrawForAutoCAD — 坐标照片批量识别并自动绘制到 DWG

针对工程测量场景的效率工具：将全站仪/RTK 手簿屏幕拍成照片后，脚本自动 **OCR 识别照片中的坐标**，并**在 AutoCAD 图纸上按坐标绘制红色圆**，替代人工逐点照屏输入。

## 功能流程

```
选择坐标照片文件夹 → 选择目标 DWG 文件 → 自动 OCR 逐张识别 → 自动打开 AutoCAD 绘图
```

1. 运行后先弹出两个选择框（照片文件夹、目标 DWG），选完即可离开，识别与绘图全自动完成
2. 每张照片识别出 **东坐标 / 北坐标 / 高程** 三项（保留小数点后 3 位，毫米精度），实时打印在控制台供核对
3. 识别成功的坐标自动在 DWG 上绘制 **半径 0.5m 的红色圆**（识别失败的照片自动跳过，不会画错点）
4. 绘制完成后自动缩放全图（ZoomExtents），图纸保持打开状态，人工确认后自行 Ctrl+S 保存

## 坐标映射规则（重要）

依据仪器屏幕的数值排列顺序（东坐标 → 北坐标 → 高程），脚本做如下映射：

| 仪器数据 | CAD 轴 | 说明 |
|---|---|---|
| 东坐标 | X | |
| 北坐标 | Y | |
| 高程 | — | 仅识别记录，平面绘图 Z 固定为 0 |

## 环境要求与安装

- Windows + 本机已安装 **AutoCAD**（通过 COM 接口操控）
- **Tesseract OCR**：默认安装在 `C:\Program Files\Tesseract-OCR`，且 `tessdata` 目录内需包含 `chi_sim` 语言包（脚本第 14 行可改路径）
- Python 3.x 依赖：

```powershell
pip install opencv-python pytesseract numpy pywin32
```

## 使用方法

```powershell
python piliangshibie.py
```

按提示依次选择照片文件夹（支持 png / jpg / jpeg / bmp）和 DWG 文件即可。

## 关键参数（piliangshibie.py 顶部）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `CIRCLE_RADIUS` | 0.5 | 圆半径（米），图纸单位需为米 |
| `CIRCLE_COLOR` | 1 | AutoCAD 颜色索引，1 = 红色 |
| `POINT_Z` | 0.0 | 圆心 Z 坐标（高程未参与绘图） |

## 识别原理

- **预处理双通道**：主通道（3 倍放大 + 高斯去噪 + Otsu 二值化）失败时，自动切换备用通道（三次立方放大 + 锐化），专治失焦/模糊照片
- **数字筛选**：从 OCR 结果中提取所有带小数的数字，仅保留绝对值 > 100 的项（过滤点号、日期等干扰），取最后三个作为东坐标、北坐标、高程
- 使用 `np.fromfile + cv2.imdecode` 读取图片，兼容中文路径

## 已知限制

- 识别准确性依赖"坐标是屏幕上最后三个大数值小数"这一版式假设，其他版式的截图可能错位
- 图纸单位需为**米**（0.5 半径才对应 0.5m）；毫米单位图纸请把 `CIRCLE_RADIUS` 改为 500
- 对同一批照片重复运行会在相同位置叠加重复圆（暂无去重保护）
- Tesseract 路径为硬编码，换机安装位置不同时需修改脚本第 14 行
